# Bina Digital — Prototype (Miawmiaw Studio)

Interactive HTML prototype for the Bina Digital light UI refresh pitch. Single file: `index.html`. All data is dummy.

**Live preview:** https://ruquruqu.github.io/binadigital/

Flows: Prelogin → Login → Homepage (incl. onboarding / empty states) → Transfer (BI-FAST/RTGS/Online and Sesama Bank INA) → Konfirmasi → PIN → Berhasil / Pending / Gagal, Bina Assistant (@mention transfer), Akun, Level Kamu, Detail Profil.

The demo panel next to the phone (desktop only) switches states for presenting.
